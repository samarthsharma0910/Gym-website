# 🏋️ EliteFit Gym — Full Stack Gym Website

A modern full-stack gym website built with a professional dark fitness aesthetic and a scalable backend architecture.

This project simulates a real-world commercial gym website featuring membership management, secure authentication, trainer listings, inquiry handling, and an admin system powered by MongoDB.

Designed with a focus on clean UI, responsiveness, and practical backend implementation.

---

## 🚀 Features

### User Features

* Responsive modern gym website
* Professional dark theme UI
* Gym equipment showcase
* Membership plans
* Trainer profiles
* Contact & inquiry form
* Trial session booking
* User authentication system

### Admin Features

* Manage gym members
* View membership details
* Handle inquiries
* Manage trainers
* Track bookings
* Secure admin access

### Backend Features

* REST API architecture
* MongoDB database integration
* Secure authentication
* Form validation
* Database CRUD operations
* Protected routes
